# Hi, I'm Abrar 👋

### Generative AI · Backend Engineering · Cloud Deployment · Data & Signal Processing

I'm a Master's student in **Medical Engineering - Medical Image and Data Processing** with hands-on experience building **AI-enabled software systems**, **LLM workflow automation**, **semantic retrieval pipelines**, **backend services**, and **cloud-deployed applications**.

I enjoy working on problems where AI is not just a demo, but part of a real workflow: taking ambiguous technical or business requirements and turning them into structured, reliable systems that people can actually use.

Currently, I work as an **IT & Digital Platforms Engineer at Siemens Energy**, where I contribute to GenAI workflow systems involving **FastAPI services, LLM orchestration, document intelligence, agentic workflows, RAG, ChromaDB, RabbitMQ, async job execution, frontend/API integration, and AWS-based deployment workflows**.

Previously, I worked at **TATA ELXSI** on connected-vehicle and IoT platforms for **TATA Motors**, building Python microservices, REST APIs, AWS IoT Core/MQTT communication, Kafka streaming workflows, and backend validation pipelines.
